# Code style

- Comment code moderately, the way a human developer would. Explain intent, non-obvious decisions and tricky logic. Don't comment every line or restate what the code already says.
- Write human-readable code: clear names, small focused functions and straightforward control flow. Prefer clarity over cleverness or brevity.

# Language

- All text shown on the site must be in Brazilian Portuguese (pt-BR): labels, buttons, tooltips, aria-labels, window titles, messages, dates and times. Product names stay as they are (e.g. "Windows Media Player").
- Where the real Portuguese Windows XP / WMP had a name for something, use that ("iniciar", "Biblioteca", "Em execução").
- Code stays in English: identifiers and comments.
